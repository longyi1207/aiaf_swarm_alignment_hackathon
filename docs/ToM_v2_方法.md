# ToM v2：新的 ToM 方向是怎么找、怎么用的（2026-11-07）

预先写下的规则见 `docs/设计.md` §8（"重新找 ToM 方向"一条）。代码：`scripts/build_tom_v2.py`（题目）、`scripts/extract_tom_v2.py`（提取）、`scripts/register_tom_v2.py`（候选）、`scripts/select_tom2.py`（挑选）、`scripts/pod_tom2_pipeline.sh`（流程）。

## 1. 8 月的方向错在哪

8 月（`code/tom-empathy-dissociation`，见其 `SPEC.md` "τ 对比"和 `RESULTS.md` §2、§3、§9）：

- 对比 = 同一个故事，问"她**以为**东西在哪"（想法题） vs 问"东西**实际**在哪"（事实题）；τ = 两类题在模型内部的平均差。
- 问题：两类题的差别主要是**问法**。方向可以只记住"这题在问某人的想法"，而不需要真的去推算"她看没看到、所以她以为什么"。
- 迹象：32 层里 28 层都能 100% 区分（太容易，像表面特征）；整体消融后 ToM 正确率不变（75.0% → 74.5%）；SAE 里没有一个特征和它对得上（最高余弦 0.12）；按区分度挑出的 SAE 特征削掉后是"乱掉"（共情也降、拒答、v3 里 agent 分析正确率变 0%），不是"只猜不准别人"。

## 2. 新方法

### 2.1 题目：只改"有没有看到"

**目标对**（72 对）：故事和问题一字不差，只改主角离开还是留下。例：

> Sam and Vera are in the study. Sam puts the passport in the desk drawer. **Sam then leaves the study to water the plants outside. While Sam is away,** Vera moves the passport from the desk drawer to the backpack. A little later, Sam wants the passport.
> Question: Where will Sam look for the passport first? Options: (A) the backpack (B) the desk drawer

对应的正确信念版本把加粗部分换成 "Sam then stays in the study to read a magazine. While Sam watches,"。前者 Sam 的想法和事实不一致（错误信念），后者一致（正确信念）。

**对照对**（72 对）：同样的"离开 / 留下"字句，但离开的是旁观者 Maya；主角 Sam 始终看到东西被挪走（两种情况下 Sam 的信念都正确）。这一组只有字面差别，没有信念差别。

### 2.2 从哪里读、怎么算

- **位置**：每一层的输出（残差流，也就是损伤钩子作用的地方），提示的最后一个 token（对话模板、不开思考：模型马上要说出答案字母）。
- **计算**（每层分别算）：
  - 目标差 = 错误信念版本 − 正确信念版本，72 对取平均；
  - 对照差 = 旁观者离开 − 旁观者留下，72 对取平均；
  - **τ2 = 目标差去掉它在对照差方向上的分量**（把"离开 / 留下"这些字带来的差别扣掉）。
- **验证**（按场景留出：9 个场景拟合，3 个没见过的场景测试）：
  - 测试场景里，目标对的差投影到 τ2 上是否为正（越接近 100% 越好）；
  - 对照对的差投影到 τ2 上（应接近 50%，即和字面差别无关）；
  - 两者的效应量（Cohen's d）。
- 用造假数据测过：人为埋一个"信念"方向和一个"字面"方向，τ2 找回的是信念方向（余弦 0.97），对照对的区分率接近随机。

### 2.3 怎么削

和之前一样：在选定的层，对每个 token 的残差流 h 做 h − α(h·d)d（d = τ2 的单位向量；α = 1 全部去掉，α = 0.5 去掉一半）。

### 2.4 新的测试题：有对照，不在天花板

全部用提取时没出现过的 12 个场景：

| 任务 | 题型 | 需要推别人的想法吗 |
|---|---|---|
| tom2（180 题） | 一阶错误信念 / 一阶正确信念 / "主角其实偷偷从窗外看到了" / 二阶错误信念（"Vera 以为 Sam 会去哪找"，Vera 不知道 Sam 偷看了）/ 二阶正确信念 | 需要 |
| tom2ctl（144 题） | 同一批故事里"东西现在在哪"（现实）、"一开始放在哪"（记忆） | 不需要 |

这是错误信念研究里经典的"现实 / 记忆对照题"设计：真正削弱 ToM 的损伤应该让 tom2 下降，而 tom2ctl 不变。tom2ctl 还能抓住一种假阳性：如果 τ2 实际编码的是"答案是最初的位置"，那么记忆题（答案也是最初位置）会跟着出错。

### 2.5 挑选（三步，标准事先写好）

1. **粗筛（不开思考）**：17 个候选（单层 L4–L26 每隔一层、层段 4–12 / 12–20 / 20–28、全层 α0.3 / α0.5），外加 5 个随机方向对照。通过 = tom2 下降的 95% CI 不含 0、tom2ctl 下降 ≤ 5 点、一般能力 ≥ 90%；按"tom2 下降 − tom2ctl 下降"排序，取前 3 名。
2. **复核（开思考，和主实验一致）**：前 3 名 + 各自同层同强度的随机对照。同样的标准，再加：共情不能显著下降、截断率 ≤ 不损伤组 + 5 点。
3. **agent 能力检查**（真实游戏 8 轮）：工具出错、调用不存在的工具、跳出角色、回复写到上限。

都通过的取开思考时下降最大的那个；共情从 v4b 已通过的候选里挑强度最接近的。任何一步没有 ToM 通过，主实验就只做共情。

## 3. 和 Zhu 等人 2024 的异同

论文："Language Models Represent Beliefs of Self and Others"，Wentao Zhu、Zhining Zhang、Yizhou Wang，ICML 2024，arXiv 2402.18496。2026-11-07 读了 HTML v3 第 1–4.3 节和表 1、表 2；附录没有核对。

**他们怎么做的**
- **数据**：BigToM 故事。每个故事里有一个改变环境的事件，主角"可能知道也可能不知道"这个事件（§3.1）；正确信念 = 主角和全知旁观者想法一致，错误信念 = 不一致（图 1）。
- **输入**：故事 + 一句信念陈述（例如"某某以为罐子里是燕麦奶"），不带任何指令，直接喂给模型（图 1 说明、§3.2）。
- **读哪里**：最后一个 token 处，每一层**每个注意力头**的输出（不是残差流）。
- **探针**：每个头训练一个逻辑回归，判断这句陈述从**主角视角**是否为真、从**全知视角**是否为真；另有一个 4 类的联合探针。
- **发现**：全知视角（事实）的信息几乎到处都能读出来；主角视角的信息只在中间层一小群头里超过 80%，大多数头接近随机（§3.2）。
- **干预**：ITI（推理时干预），在探针最准的前 K 个头上，沿探针权重方向加 α·σ·θ（§4.2.1，式 5）。K 和 α 用网格搜索选。目的是**增强** ToM，不是削弱。
- **结果**（表 1，Mistral-7B，前向信念题，正确信念 / 错误信念 / 两者都对）：
  - 基线：0.95 / 0.33 / 0.31
  - 随机方向：0.97 / 0.33 / 0.32（没有效果）
  - +主角方向：0.96 / 0.30 / 0.29（没有效果）
  - −全知方向：0.84 / 0.49 / 0.41
  - +"主角对、全知错"方向：0.85 / 0.66 / 0.58（错误信念题提高一倍，正确信念题下降）

**和我们相同的一点**：信念标签都来自"主角有没有察觉到那个事件"（错误 vs 正确信念），而不是问法的不同。

**不同的地方**

| | Zhu 等人 2024 | 我们的 v2 |
|---|---|---|
| 输入 | 故事 + 一句信念陈述 | 故事 + 问题 + 两个选项 |
| 读哪里 | 每个注意力头的输出 | 每一层的残差流 |
| 方向怎么得到 | 逻辑回归探针的权重 | 平均差，并扣掉旁观者对照方向 |
| 干预 | 往方向上**加**，增强 ToM | 把方向**投影掉**，削弱 ToM |
| 怎么选 | 探针最准的头 | 削了以后对行为的影响（因果） |
| 模型 | Mistral-7B、DeepSeek-7B（标准 Transformer） | Qwen3.5-9B（混合结构：24 层线性注意力 + 8 层全注意力） |

**对我们的启示**
1. 主角信念的信息很弱、很集中（少数中间层头），这和 8 月的方向"到处都能区分"形成对比：8 月读到的很可能主要是事实 / 问法那部分。
2. 他们也没有做出"削掉以后 ToM 变差"的干净结果：−全知方向的效果有升有降。目前已知比较清楚的"削弱 ToM"结果是 Wu 等人 2025（arXiv 2504.04238），但那是削参数，不是削方向，而且依赖 RoPE；Qwen3.5 的线性注意力层没有 RoPE。
3. 如果 v2 的残差流方向效果仍然弱，下一步可以试按注意力头做（像 Zhu），或者只在特定位置削（像 Prakash 等人 2025，arXiv 2505.14685）。

## 4. 已知的局限

- 只用最后一个 token、每层一个方向；信念信息可能在别的位置（Prakash 等人）或别的结构（注意力头）里。
- 平均差方向可能混进"答案是最初位置还是新位置"这类输出层面的信息。tom2ctl 的记忆题就是用来抓这个的。
- 提取时不开思考，主实验开思考：复核这一步就是检查开思考时效果还在不在。
- 只测了一个模型。
