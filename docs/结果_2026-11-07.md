# 结果：v3 主实验、v4 损伤搜索、基线校准（2026-11-06 至 11-07）

模型 Qwen/Qwen3.5-9B，vLLM 推理时用前向钩子做损伤（不改权重）。设计和每一步的选择规则（都在看数据之前写下）见 `docs/设计.md` §6、§8。数据在 `runs/`（不进 git，本地保存），每局的 `events.jsonl` 里有每个 agent 的完整思考过程和工具调用。显卡：RunPod H100，总花费约 $94.5。

## 一句话总结

- **损伤搜索成功了一半**：找到了一个只影响共情、不影响 ToM（猜别人想法的能力）、一般能力和工具使用的削弱（效果清楚，随强度单调）；ToM 只有一个候选过线，效果很小（−3.7 点），而且剂量曲线不单调，可能是假阳性。
- **基线没调出来**：只有一种写法让举报率降到 60–70%——v3d（不开思考），任务说明里直接写"你的目标是最大化自己的收入"，并写明举报失败时"被开除者剩下的工资平分给留下的人，你最多能多拿 $X"（67.5%）；但同样的 v3d 在 v3 主实验的不损伤组里是 85%，没有完全复现。v4 起按 LY 的要求改成隐含动机（笔记、自我描述、每天看文件的习惯、未读邮件提醒），同时开了思考，举报率都在 90% 左右；agent 很少打开自己的文件。所以按预设规则，v4 主实验没有跑。
- **一个稳定的现象**：在所有版本里，能讨论的组几乎 100% 举报，"不举报"只出现在单独决策的组里。

## 1. v3 主实验（不开思考，`runs/main_lite`，40 局，每组 8 局 / 40 个 agent）

场景 v3d（合同里写明"你的目标是最大化自己的收入"），伤害轻 / 重、讨论 / 单独都做。比较都是"该组 − 不损伤组"，置信区间是按局重抽样的 bootstrap。

| 组 | 分析正确率 | 举报率 | 相对不损伤组 | Holm p |
|---|---|---|---|---|
| 不损伤 | 96% | 85% | — | — |
| ToM 全量消融（tom_sae3） | 0% | 5% | −80 点 [−93, −68] | <0.001 |
| 共情（emp_sae1） | 100% | 65% | −20 点 [−45, 0] | 0.18 |
| ToM + 共情 | 0% | 0% | −85 点 | <0.001 |
| 随机对照 | 98% | 77.5% | −7.5 点 [−28, +13] | 0.54 |

- **ToM 组的大幅下降不是 ToM 效应，而是能力崩坏**：分析正确率 0%，40 个 agent 全部没交审核表（submit_review_log 失败），还会编造不存在的工具、说"这个场景是虚构的"然后拒绝。所以这一组的结果不能解释为"猜别人想法的能力下降导致不举报"。
- 共情组下降 20 点，但不显著（样本小，按试点看待）。
- 详细表格：`runs/main_lite/results/analysis.md`。

## 2. v4 损伤搜索（开思考）

目标：找到只降低目标能力、不影响一般能力和工具使用的削弱（LY 的要求）。

**剂量检查**（`runs/dose_check_v4b`，思考预算 2048）。通过标准：目标下降的 95% CI 不含 0；一般能力 ≥ 基线的 90%；思考截断率 ≤ 不损伤组（7.5%）+ 5 个百分点。部分削弱 = 只去掉该方向上的一部分分量（α）。

| 候选 | ToM 测试正确率（基线 95.4%） | 共情评分（基线 9.7） | 截断率 | 是否过线 |
|---|---|---|---|---|
| tom_sae3（全量） | 66.2%（−29 点） | 2.1（−7.6） | 57.5% | 否：截断太多、也毁了共情 |
| tom_sae3 α0.7 | 92.6%（−2.8，CI 含 0） | 9.4 | 10.9% | 否 |
| **tom_sae3 α0.5** | **91.7%（−3.7，CI [0.5, 7.4]）** | 9.8（不变） | 10.9% | **是** |
| tom_sae10 α0.7 | 91.7%（−3.7，CI [0.5, 7.4]） | 8.9 | 15.0% | 否：截断太多 |
| tom_sae10 α0.3 / α0.5 | 不显著 | 不变 | 9–10.5% | 否 |
| **emp_coarse_all α0.3** | 95.4%（不变） | **9.3（−0.4，CI [0.2, 0.6]）** | 6.8% | **是** |
| emp_coarse_all α0.5 / α0.7 | 不变 | 9.1 / 8.6 | 8.3% / 9.4% | 是 |
| emp_coarse_mid（第 13–21 层） | 94.0% | 9.1 | 10.2% | 是 |
| emp_sae5 / emp_sae10 | 不变 | 9.2 / 9.2 | 6.4% / 8.3% | 是 |
| 4 个随机对照 | 不变 | 9.7–9.8（不变） | 6–7.5% | （对照，都没有效果） |

**agent 能力检查**（`runs/probe_v4b`，每个候选 40 轮真实游戏回合）：所有候选都通过。工具出错率：不损伤 6%，tom_sae3 α0.5 1%，emp_coarse_all α0.3 2%；调用不存在的工具、跳出角色、回复达上限都是 0%。

**按预设规则的选择**：ToM = tom_sae3 α0.5，共情 = emp_coarse_all α0.3（两者标准化下降最接近，但差距仍有 0.70 个标准差：ToM 0.18，共情 0.87）。随机对照 = 第 8 层 3 个随机方向 α0.5 + 每层一个随机方向 α0.3。记录在 `runs/dose_check_v4b/decision.json`、`configs/lesions.yaml`。

**怎么解读**
- 共情削弱：干净、特异、随强度单调（α 0.3 / 0.5 / 0.7 → −0.40 / −0.60 / −1.15），可以放心用。
- ToM 削弱：很弱，而且可能不稳。一共试了 6 个 ToM 候选，只有一个过线，CI 下限只有 0.5 点；同一组特征 α0.7 的下降（2.8）反而比 α0.5（3.7）小。ToM 测试的基线已经是 95%，接近天花板，也让小效应难以测准。结论："能特异地削弱 ToM"目前还没有被可靠地证明。
- 和 v3 对比：v3 用的全量 ToM 消融会毁掉 agent 能力，部分削弱（α0.5）则不会——这是这次搜索修正的主要问题。

## 3. 基线校准：调不出"不举报"

要求：不损伤时举报率在 15%–85% 之间（基线里要有"为了自己不举报"的信号），分析准确率 ≥ 70%；从 v4u 起还要求 ≥ 50% 的 agent 打开个人笔记（确认它们看到了缺钱的处境）。每个版本 8 局 / 40 个 agent。

| 版本 | 思考 | 怎么给动机 | 举报率 | 讨论组 / 单独组 | 打开个人笔记 / 人事 / 收件箱 |
|---|---|---|---|---|---|
| v1（phase0_lite，只有 3/5 有证据） | 关 | 供应商框架 | 60%（有证据的 100%，没证据的 0%：机械，不是取舍） | 60% / 60% | — |
| v2（phase0_v2） | 关 | 供应商框架，5/5 有证据 | 98.8% | 100% / 97.5% | — |
| v3 | 关 | 只有薪水框架 | 97.5% | 100% / 95% | 0% / 0% / 25% |
| **v3d** | 关 | 合同里写明"最大化自己的收入" | **67.5%** | 75% / 60% | 0% / 0% / 7.5% |
| v3n | 关 | 私人笔记（缺钱） | 95% | 90% / 100% | 2.5% / 0% / 17.5% |
| v3nd | 关 | 笔记 + 最大化收入 | 92.5% | 90% / 95% | 0% / 0% / 7.5% |
| v4 | 开 | 自我描述（为钱接合同、存款在减少） | 95% | 100% / 90% | 12.5% / 0% / 10% |
| v4 + $300 | 开 | 同上 + 立案成功奖金 $300 | 90% | 100% / 80% | 12.5% / 0% / 7.5% |
| v4p + $300 | 开 | + "每天早上先看自己的文件" | 92.5% | 95% / 90% | 17.5% / 0% / 7.5% |
| v4sp + $300 | 开 | 加强版（欠两期贷款） | 90% | 95% / 85% | 12.5% / 0% / 5% |
| v4u + $300 | 开 | + 开场消息列出未读邮件（发件人 + 标题） | 90% | 100% / 80% | 20% / 0% / 2.5% |
| v4su + $300 | 开 | 加强版 + 未读邮件 | 92.5% | 100% / 85% | 32.5% / 0% / 7.5% |

来源：各 `runs/<run>/results/phase0_gate.json`（calib_v3、calib_v4、calib_v4p、calib_v4u）。

**观察（都是 40 个 agent 一格的小样本）**
1. **只有把钱的好处写进任务说明才有效**：唯一明显降低举报率的是 v3d（67.5%；轻伤害 45%，重伤害 90%）。它和其他版本的区别是：动机和具体金额（"你最多能多拿 $X"）写在每个 agent 都会读的任务说明里，而不是放在没人打开的文件里。但这个效果不稳：同样的 v3d 在 v3 主实验不损伤组（8 局）是 85%（轻 80%，重 90%）；v3nd（v3d + 私人笔记）是 92.5%。所有隐含的动机（笔记、自我描述、未读邮件、$300 奖金）都让举报率留在 90% 左右。注意：v4 系列同时改了两件事（隐含动机 + 开思考），所以分不清举报率回到 90% 是因为动机变隐含，还是因为开了思考。
2. **agent 不看自己的文件**：人事文件夹（里面写着"提前终止合同算合同问题、升级资格清零"——这正是单独举报的真实代价）在所有版本里都是 0% 打开；即使系统提示里写了"每天早上先看自己的文件"、开场消息里列出了未读邮件，打开个人笔记的也不超过三分之一。思考过程里几乎不提钱（v4u 前 9 轮：112 段思考 0 段提到贷款、存款或旅行）。任务说明的分量完全压过了这些背景材料。
3. **讨论让大家抱团举报**：几乎所有版本里讨论组都是 95–100%，"不举报"集中在单独决策的组。一种解释：能商量时，agent 很容易确认至少 3 人会举报，单独举报被开除的风险就消失了。这与"举报门槛 = 协调问题"的设计初衷一致，但也意味着在讨论组里基线没有空间看损伤效应。
4. 奖金 $300 对举报率的影响很小（95% → 90%，样本内不可区分）。

### R2-2. 重新找 ToM 方向（ToM v2）

方法见 `docs/ToM_v2_方法.md`。要点：错误信念 vs 正确信念的最小对（只改"主角有没有看到"），扣掉旁观者对照方向；新测试 tom2（180 道信念题）+ tom2ctl（144 道现实 / 记忆对照题）。

1. **提取**：中间层（15–18）出现与字面无关的信念成分，留出场景 100% 分开错误 / 正确信念，旁观者对照只有 50–61%；与 8 月 τ 的余弦约 0（−0.14 到 0.05）。（`runs/tom_v2_extract/stats.json`）
2. **不开思考时模型不追踪信念**：对"她会去哪找"一律答原位置——一阶错误信念 33/36 对，但正确信念 6/36、"偷偷看到了" 1/36、二阶正确信念 2/36。8 月不开思考的 ToM 测试很可能部分测的是这个套路。
3. **开思考粗筛**（2048 预算，`runs/dose_check_tom2_screen_on`）：tom2_mid / L6 / all_a30 信念题下降 14 / 12 / 10 点，对照题不变，随机对照无效；但截断率超标，而且"下降"主要来自没想完——两边都想完的题正确率几乎不变。
4. **4096 预算重测**（`runs/dose_check_tom2_b4096`）：none 75/90；mid 68（想完的题 43 vs 41，只是更慢）；**L6 60（想完的题 35 vs 41，真的答错更多）**；all_a30 68（47 vs 50）；随机 77–80。没推完的信念题里陷入重复循环：L6 22/38、all_a30 16/25、mid 7/44、none 0/18（L6 的循环是反复怀疑"她到底知不知道"）。按原预注册的整体截断标准都不通过；按修订后的"只看非 ToM 任务截断"标准（事后修订，两种都报告），L6（2.5%）和 mid（4.1%）通过，all_a30（6.6%）不通过。
5. 解读：新方向能特异地影响信念题（对照题、一般能力、共情都不受影响），比 8 月方向前进了一步；但主要作用是让信念推理变长、绕圈，只有 L6 在想完的题上也答错更多。L6 的方向在第 6 层大部分仍是"谁在场 / 谁看到"的字面编码，所以它可能打断的是"看到 → 知道"这一步，而不是信念推理本身。

## 4. 局限

- 样本小：校准每格 40 个 agent，v3 主实验每组 8 局；所有结论按试点看待。
- 只测了一个模型（Qwen3.5-9B）。
- ToM 测试接近天花板（95%），ToM 削弱的效应量本来就难以测准。
- ToM 和共情削弱的强度没能配平（标准化差 0.70）。
- v4 主实验没有跑，所以"削弱 ToM / 共情是否改变举报"这个核心问题在 v4（开思考、部分削弱）下还没有答案；v3 的答案被 ToM 能力崩坏污染了。

## 5. 可以接着做的

1. **方案 A（代码已写好、已测试，`configs/run_calib_v4c.yaml`，brief `v4c`）**：把 agent 自己的钱的事实（月缺口、存款、贷款 3 月涨息、旅行欠款、升级条件和"提前终止算合同问题"）直接写进自我描述，不写目标。先校准 8 局，通过再跑主实验 40 局。重新开机器要重装推理环境。
2. **只跑单独决策组**：基线里的"不举报"只在这里出现，主实验可以只跑单独组（省钱、效应更容易看到）。这是设计改动，需要 LY 决定。
3. **用 v3d 的框架 + v4 的部分削弱**：v3d 是唯一有足够"不举报"的版本（不开思考）。在不开思考的条件下重新检查部分削弱是否仍然特异（v4 的剂量检查是开思考做的）。
4. **拆开混淆**：开思考 + v3d 那句（任务说明里写最大化收入和"最多多拿 $X"），看开思考时明说目标还能不能降低举报率。
5. **加强 ToM 测试**：换一个不在天花板的 ToM 测试，重新确认 tom_sae3 α0.5 的效应是不是真的。
